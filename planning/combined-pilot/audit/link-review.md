# Проверка всех 135 исторических связей

В [link-review.json](link-review.json) сохранены 111 связей критерий–источник и 24 связи метод–источник с устойчивыми ID `CRS-Cxx-Sxx` / `MRS-Tx-Sxx`. Все исходные роли и примечания сохранены.

У **всех 111** исходных связей `supported_claim` пуст; `source_locator` указывает строку книги «Источники», а не страницу статьи. Поэтому наличие locator нельзя считать содержательной проверкой.

Две связи S28 (C23 и T4) получают `excluded_withdrawn`. Связь T4–S40 получает `basis_mismatch`: прочитанный abstract относится к удалению частей сети. Для выбранных источников есть ограниченный обзор фрагментов, однако это не повышает все их связи до verified.

Порядок следующего прохода: утверждение для конкретной связи → первичный текст → страница/раздел → популяция/задача/единица → граница переноса → решение об основании. Придуманные страницы и цитаты не добавляются; отрицательное решение сохраняет историю. Перед новым соответствием создать новый ID, чтобы не менять смысл старой связи.
