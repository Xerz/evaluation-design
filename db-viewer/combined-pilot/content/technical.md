# Запись и технические профили

## Технический смысл модальностей

**Авторство:** Коды профилей, QC и варианты размещения предложены Codex: [AI-14](authorship.html#ai-14).

Оборудование определяется измерительной задачей. Аудио для ASR, акустические признаки, видеозапись для эксперта, видео лиц аудитории для МГПУ и запись слайдов/экрана — разные назначения с разными требованиями. Наличие камеры не доказывает пригодность любого из этих входов.

| Профиль | Назначение | Что требуется проверить |
| --- | --- | --- |
| TP-AUDIO | Транскрипт и аудиопризнаки | Слышимость преподавателя и реплик студентов, обрезания, шум, перекрытия, ASR/диаризация, длина пригодного участка |
| TP-EXPERT-VIDEO | Экспертный референс по записи | Преподаватель, значимые реакции/действия, слайды/доска по задаче; синхронный полноценный звук |
| TP-MGPU-VIDEO | Видеовход МГПУ | Требуемые лица/ракурсы, освещение, закрытия, охват и реальные требования конкретного модуля |
| TP-CONTENT | Предметный контекст | Слайды, экран/доска, задания, цели и программа; точное соответствие времени/версии материала |
| TP-OA / TP-OV | Наши дополнительные модальности | Только после подтверждения собственного обработчика, его требований и полезного выхода |

Базовый продуктовый профиль — аудиоконтур с допустимым результатом по тем критериям, где его достаточно. Видео может быть необходимо для референса эксперта в эксперименте и при этом оставаться дополнительным для конкретной поставки продукта.

## Минимальный аудиопрофиль

Первый обязательный контур — транскрипт. Проверить слышимость преподавателя и реплик студентов, шум, обрезания, перекрытия речи, пригодную длительность и качество распознавания. Аудио, использованное только для транскрипта, не считается самостоятельным аудиоанализом.

## Видео для экспертов и для машины

Экспертному просмотру могут понадобиться действия преподавателя, доска, слайды и значимые реакции. Машинный видеовход имеет отдельные требования к лицам, ракурсам, освещению и охвату. Камера, пригодная для одного назначения, может быть недостаточна для другого. Нужно ли видео для конкретной поставки, определяется по проверяемым критериям.

## Контроль качества и происхождение

Паспорт записи хранит дату и часовой пояс, конфигурацию оборудования, назначения модальностей, происхождение и checksum файла, длительность исходного и пригодного участка, потери сигнала и синхронизацию. Для транскрипта — версии ASR и диаризации, сегментацию, вычитку и происхождение таймкодов.

Старое ТЗ указывало MP4/H.264, 720p, до 90 минут и 512 МБ. Это историческое ограничение загрузки, которое нужно проверить для текущей версии МГПУ; оно не задаёт универсальный стандарт записи.

## Инфраструктура и затраты

**Авторство:** Параметры арифметических примеров выбраны Codex; это не требования качества: [AI-17](authorship.html#ai-17).

Оба варианта [поставки](product.html) требуют оценки вычислений, времени обработки, хранения, сети, диагностики, обновления и поддержки. Стоимость считать на пригодное занятие с учётом ошибок записи и ручной работы. Численные требования и цены пока не утверждены.
