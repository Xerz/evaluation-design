# Публичная документация объединённого пилота

Этот каталог хранит отредактированную публичную версию готовых материалов из `planning/combined-pilot/`. Сборщик не копирует рабочий план, его каталог источников, PDF встречи или операционные выгрузки в сайт.

`content/*.md` — публичные исходники десяти страниц. `page.html`, `style.css` и `reading.js` — шаблон, оформление и раскрытие карточек по прямым ссылкам. `publish_combined.py` создаёт раздел `combined-pilot/` внутри полного статического экспорта. `docs/` и `_site/` — производные, их нельзя редактировать вручную.

При изменении решения сначала обновить рабочий план и журнал, затем соответствующий публичный текст. Сохранять исходные шкалы и методические поля; утверждения новой версии не должны выдавать исторический статус за новую проверку. Коды C/S/T/E и конфигураций служат исследовательской навигации; внутренние задачи, пути к локальным файлам и реальные внешние ID в публичный текст не включать.

После установки `db-viewer/requirements.txt` собрать сайт и выполнить `db-viewer/check_public_site.py --site <каталог сборки>`. Проверка сверяет 26/78 и полные методические поля с read-only БД, ссылки/якоря, 13 карточек-кандидатов МГПУ и schema-only экспорт операционных таблиц. Полная библиографическая и содержательная проверка статей остаётся отдельной работой.

Статус этой версии — `research_draft`. Черновая БД реализована; новый просмотрщик и автономный трёхминутный HTML ещё не созданы. Решения Codex помечены рядом с деталями и на странице `authorship.html`; источник реестра — `planning/combined-pilot/audit/assistant-decisions.json`. Сверку производных выполняет `render_assistant_decisions.py --check`.
